## إدارة محتوى الموقع

تتم إدارة العروض من جدول `diva_offers`، وإدارة صور الموقع القديمة والجديدة من جدول `diva_site_images`.
شغّل `site-images-migration.sql` مرة واحدة في Supabase بعد رفع هذه النسخة لاستيراد العروض الستة والصور التسع القديمة وضبط صلاحيات القراءة العامة.


## رفع صور واتساب الجديدة وإدارتها

1. ارفع ملفات المشروع إلى GitHub Pages.
2. افتح لوحة التحكم ثم تبويب **كل صور الموقع**.
3. فك ضغط مجلد `diva-new-photos` واختر الصور الأربع عشرة كلها من أداة الرفع الجماعي.
4. اضغط **رفع الصور المختارة**. الصور تذهب إلى Supabase Storage، وتُنشأ سجلاتها في `diva_site_images` بأسماء وتصنيفات وأماكن ظهور أولية.
5. يمكنك تعديل الاسم والتصنيف والنص البديل ومكان الظهور، أو إخفاء الصورة أو حذفها من نفس اللوحة.

**مهم:** لم تتم إضافة أي عروض جديدة ولم تعدّل هذه النسخة العروض الموجودة. رفع الصور لا يغيّر جدول العروض.

### تحديث قاعدة البيانات
إذا كان جدول `diva_site_images` موجودًا بالفعل، شغّل مرة واحدة في Supabase SQL Editor:
```sql
ALTER TABLE public.diva_site_images
ALTER COLUMN sort_order TYPE bigint
USING sort_order::bigint;
```
هذا يمنع خطأ تجاوز الحد الأقصى لنوع integer في ترتيب الصور.

### الحذف
عند حذف صورة مرفوعة إلى `diva-media`، يحذف النظام ملف التخزين أولًا ثم سجل قاعدة البيانات. إذا فشل حذف الملف، يتوقف ولا يحذف السجل. قد تحتفظ ذاكرة المتصفح أو CDN بنسخة مؤقتة لبعض الوقت. الصور القديمة المستضافة خارج Supabase يمكن إزالتها من DIVA، لكن لا يمكن حذف النسخة الأصلية من خادم خارجي لا نملكه.
